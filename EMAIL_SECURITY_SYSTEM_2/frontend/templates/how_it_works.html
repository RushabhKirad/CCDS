How the Engine Decides

A deep dive into our Multi-Layer Cognitive Fusion logic

01
Ingestion & Normalization

The system fetches emails via IMAP/SSL. It strips HTML tags, decodes Base64 attachments, and normalizes the text for the NLP engine.

02
Multi-Modality Analysis

Three parallel brains analyze the data:
• The Vision Brain (OCR): Scans images for "hidden" text.
• The Context Brain (BERT): Understands the sentiment and intent.
• The Network Brain (URL): Checks the SSL and domain age.

03
Weighted Ensemble Fusion

The Cognitive Fusion Algorithm assigns weights. If an email has no links, it gives 100% weight to Text. If it has a suspicious link and a safe sender, it balances the scores to provide a balanced threat probability.

04
Classification & Result

A final decision is made. If the threat score resides in the "Red Zone" (>0.7), the email is flagged and a detailed threat explanation is generated for the user.
